# Stock icon ids

Every id below can be passed as `iconId` in `config.json`, to `wh.Title` or to `wh.IconPS`. Stock
glyphs are white shapes; see [Glyphs and images](glyphs.md) for sizing, tinting and
your own image glyphs.

The list holds the 1089 ids that `IconPS.iconIds` returns on a FW 13.20 console. Other
firmware may add or drop a few, so check an id at runtime when it matters:

```js
var ok = wh.IconPS.iconIds && wh.IconPS.iconIds.indexOf(id) >= 0;
```

`IconPS` does not check ids itself: an id that is not on the list draws nothing.
